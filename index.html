✂️ HHS Clips

Cut. Approve. Post. — your own videos only.

Long video in, short clips out.

Drop in a video you own — a podcast, talk, webinar, demo, or stream VOD — and the app cuts the best short vertical moments, with captions, for you to approve.

Only clips you approve can post, and only when you tap Post. YouTube posts as Private, TikTok as Self-only, until those apps pass their audits. Dry-run is on by default, so nothing posts by accident.

This page is just the front door. The app itself runs on your own computer or phone — this site can't run it for you. Pick a way to run it below.

Run it on your phone

Termux, from F-Droid (not the Play Store):

  1. pkg install -y python ffmpeg git
  2. git clone https://github.com/hhsystems1/hhsclip.git
  3. cd hhsclip && python3 server.py
  4. Open http://localhost:8000 on the phone.

Full steps, downloads and the whisper model: TERMUX.md

Run it on your computer

  1. git clone https://github.com/hhsystems1/hhsclip.git
  2. cd hhsclip && python3 -m venv venv && ./venv/bin/pip install -r requirements.txt
  3. ./venv/bin/python server.py --host 0.0.0.0
  4. Open http://localhost:8000 — or from your phone, http://<computer-IP>:8000.

Needs ffmpeg installed. Full setup and posting accounts: README.md
